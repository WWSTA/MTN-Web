CPU-only Browser ONNX

MOSS-TTS-Nano

0.1B 参数多语言语音合成模型，纯浏览器端运行。支持中文、英文、日语、韩语等近 20 种语言。 无需后端服务，无需 GPU，打开即用。

基于 OpenMOSS/MOSS-TTS-Nano 开源项目， 使用 ONNX Runtime Web 在浏览器中运行推理。

模型配置

模型文件需放在 models/ 目录下。请先运行 python download_models.py 下载模型（约 700MB）， 或手动从 HuggingFace 下载后放入对应目录。

点击"加载模型"以初始化 ONNX 推理引擎（首次加载约需 30-60 秒）。
